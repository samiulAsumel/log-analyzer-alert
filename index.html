Get started

One-command install

Auto-detects systemd and installs timers. Falls back to cron on older systems.

Clone
git clone https://github.com/samiulAsumel/log-analyzer-alert.git
Configure
nano config.conf # set ALERT_EMAIL, SLACK_WEBHOOK, PAGERDUTY_KEY
Install
sudo bash install.sh
Verify
bash /usr/local/bin/loganalyzer/scripts/health_check.sh
How it works

Pipeline architecture

Cross-log intelligence

Threat correlation engine

detect_threats.sh runs after all modules and correlates their findings to catch attacks that no single module can see alone.

Persistent Attacker
Same IP appears in both SSH brute-force and nginx 404 storm — coordinated reconnaissance and intrusion attempt.
AUTHNGINX
Multi-Service Failure
CRITICAL or HIGH findings across 3 or more module categories simultaneously — likely intrusion or infrastructure cascade.
AUTHNGINXSYSTEM
Application Overload
OOM kill detected at the same time as app CRITICAL entries — memory leak, traffic storm, or runaway process.
SYSTEMAPP
Account Compromise
Brute-force SSH followed by new user creation in the same interval — attacker may have gained access and created a backdoor account.
AUTH bruteAUTH new user
Data Integrity Risk
Disk full and MySQL errors occurring together — database writes are failing and data loss may be imminent.
SYSTEMMYSQL
Active Reconnaissance
Web scanning and SSH brute-force in the same interval — target is being actively probed across multiple attack surfaces.
NGINXAUTH
Cross-log IP Scan
External IP appearing 10+ times across auth, nginx, and syslog combined — suspicious access pattern worth investigating.
